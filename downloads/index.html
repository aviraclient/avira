Option one

Avira Launcher

Installs our launcher for your Windows user, with Desktop and Start menu shortcuts. It downloads Minecraft and Java 8 for you, keeps itself and Avira up to date, and lists featured servers you can join in one click. Sign in with your Microsoft account to play on any server, or use an offline account for singleplayer and cracked servers.

Option two

Minecraft Launcher

Adds an "Avira Client" profile to the official Minecraft Launcher, with its own game folder. You sign in with Microsoft as usual, so it works on Hypixel and other premium servers. Avira downloads new versions in the background and tells you when to restart.

"Windows protected your PC"

The setup isn't code-signed yet, so Windows SmartScreen may warn you the first time. Click More info, then Run anyway. You can check the file matches the SHA-256 above first: in PowerShell, run Get-FileHash Avira-Setup.exe.

Uninstalling

The Avira Launcher shows up in Windows Settings, under Apps, like any other program. For the Minecraft Launcher option, delete the "Avira Client" installation in the launcher.

What changed

Every change to the client, launcher, installer and this website is on the Updates page. Downloads are hosted on GitHub Releases, where you can also find older versions.
